# 松间叩仙微信小程序

原生微信小程序客户端，不依赖 npm 构建。使用微信开发者工具直接导入此目录。

仓库默认使用游客模式（`touristappid`）。预览、真机调试或发布时，在本地的
`project.private.config.json` 顶层添加 `appid`，填入微信公众平台的小程序 AppID。
该文件已被 Git 忽略。先添加此字段，再在开发者工具中修改 AppID，工具就会把修改写入私有配置。

发布前必须完成：

1. 确认开发者工具使用私有配置中的目标小程序 AppID。
2. 当前 `config/env.js` 的 API 和静态资源都连接开发机局域网地址 `http://192.168.101.2:3001`，正式发布前改成 HTTPS 服务地址。
3. 在微信公众平台登记 `request` 合法域名。
4. 当前小程序使用道号和口令登录，个人主体无需开通手机号快速验证能力。

开发阶段可在微信开发者工具中临时关闭“校验合法域名”，并把 API 地址改为局域网可访问的
开发机地址；真机不能通过 `127.0.0.1` 访问电脑上的后端。
